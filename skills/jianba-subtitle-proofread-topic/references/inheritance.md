# 指定话题与全片覆盖

本页处理指定话题改字能否被全片看到；文字操作遵守[主流程](../SKILL.md)的文字专用规则。固定目标 topic，只完整读取并校对该话题当前 screen。不要扫描其他话题、重做全片校对，或把 automatic 当作当前文字基线。已有人工改字始终以实际 screen 为准。

读取全片 screen 元数据，检查 `screen.mode`、`screen.scope.inheritance`、覆盖关系与 stale 状态；这里只判断传播关系，不扩大校对范围。全片继承话题时，目标话题保存并应用后，其字幕会按全片时间线映射到画面。不建立全片文档，不把话题展示时间复制成全片时间，也不应用 inherited 或 automatic 重置选择。

全片存在覆盖时，话题改字不会自动更新全片；`overrides.upstreamChanged` 只提示上游变化，并不表示已经同步。先按目标话题当前 screen 修复证实错误，保存并应用。随后取得最新全片 screen 绑定，读取定位目标字幕所需的内容；只为同步已确认的目标错误查看这些字幕，不校对其他话题。

跨范围定位必须以完全相同的有序 wordIds 确认一对一内容单元，并独立核实目标错误在两侧当前文字中的落点；两侧整句措辞不必相同。用全片当前 cue ID 提交操作，不能直接复用话题 cue ID、按时间接近猜对应，或根据来源链推断所有权。全片继承时 cue 的 `provenance.scopeId` 可辅助归属；已有全片覆盖可能缺失该字段，或保留旧来源，仍须核实真实词集和文字。

可以可靠一对一对应时，在现有全片 screen 基线上仅修目标错误，保存并应用全片文字增量文档。话题和全片是两个独立的当前文字基线：各自只改已证实的错误，已经正确的内容不写。不得把话题改后整句直接覆盖全片原句，借同步带走全片已有的其他人工修改。

不同人工措辞不自动阻止修正其中证实且可唯一定位的同一错字；只替换该错误片段，保留其余文字和换行。若改写导致错误落点不明、分组不同、cue 跨越话题、词集只能多对一对应，或无法确认两处是同一错误，保留该处全片字幕并报告未同步部分。仍可完成可靠的话题改字及其他有明确对应的目标错误。不能为同步改分组、改时间、恢复继承，或用另一个范围的文字替换不明内容。

所有保存和应用串行执行。话题写入后，先前取得的全片绑定也可能失效；重新读取当前来源，不仅替换 expectedVersion。保存草稿后按返回查询读取该文档，再应用最新 revision。发生冲突时重读并重新核实当前文字，避免用户刚改好的内容被旧校对结果覆盖；不必重新检查没有变化的其他话题。

最终分别说明目标话题是否已上屏，以及全片是否继承或已可靠同步。仅保存文档不算生效；仍被全片覆盖遮住的错误必须明确列出，不能把话题应用成功说成全片同步完成。需要实际画面核对时按主流程选择目标范围，局部预览不代表整片已验证。
