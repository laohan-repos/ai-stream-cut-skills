# 教学内容的删留对照

## 何时读

遇到“像重复但可能有新信息”、口误纠正、参数或提示词修订、失败尝试等难以判断的片段时读取。以下均为教学假设，用于说明判断方法；不代表素材实际包含这些内容，也不承诺某种工具效果。

### 1. 重复表述与递进解释

- **可考虑删**：讲者连续两次说明同一结论，后一次没有补充适用条件、原因、例子或操作，且删除不会断开指代与语气。
- **应保留**：先说“结果要检查”，随后说明“重点检查文字是否被改写”；后一句把笼统要求变成可执行标准。相似措辞不等于信息重复。
- **取证**：听完整个论述单元，确认前后句承担的作用。只凭字幕词面相似，不能认定重复。

### 2. 口误纠正涉及关键信息

- **可考虑收紧**：讲者说错参数后立即更正；若素材中存在自然、完整的正确表述，可去掉无教学价值的失言与犹豫。
- **应保留**：错误值已经输入并影响结果，或纠正同时解释了单位、范围、易混概念。此时需要保留“原值为何不对、正确值是什么、实际改在哪里”的必要证据。
- **取证**：核对声音与界面中的值，确认最终生效值。不能只修字幕，也不能拼出讲者未表达过的确定结论。

### 3. 参数或提示词修订

- **可考虑删**：同一句提示词反复朗读，或光标移动没有帮助观众理解，且关键文本已有足够阅读机会。
- **应保留**：从“写一段介绍”改为补充受众、用途与约束，并对照结果解释变化。旧版本、修改点与结果之间形成教学关系，需要让观众能追溯。
- **取证**：确认修改前后的实际文本、提交动作及对应输出。长提示词不必逐字念完，但画面中的关键差异必须可读；不能用口播猜出不可见的内容。

### 4. 失败尝试与排错

- **应清理**：同一等待或重试反复出现，经声画核实未提供新的错误信息、判断或处理方法；保留必要上下文，优先删除机械执行的空等中段。
- **应保留**：错误表现、判断依据、关键修复与验证结果共同解释问题如何解决。失败是教学材料，不能仅因“没成功”就删除；也不能因为一次重试含有修复，就保留其全部运行过程。
- **取证**：核对错误与后续操作是否确有关联，确认修复后的结果。若素材只展示再次成功，不能补写成已证明某项修改解决问题。

### 5. 教学作用与固定结构

- **可考虑删**：离题闲聊或另一种说法，既不服务本段主题，也不承担必要衔接。
- **应保留**：纯讲解中的类比、反例、限制条件，或操作中解释“为什么这样做”的一段话。它们未必构成独立步骤，却可能是理解前提。
- **取证**：按本素材已有的教学目的判断，不要求每条教程都凑齐“目标、步骤、案例、总结”等结构，也不因缺少某环节自行补造内容。

判断仍不确定时，回到对应原片段补听、补看。优先复用来源与时间范围未变化的已有证据；不以固定删减率决定保留多少内容。
