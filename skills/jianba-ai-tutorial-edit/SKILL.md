# 剪吧 AI 教程剪辑

让观众理解讲解、跟上操作、看清结果。默认自然偏紧：必要讲解、关键操作与结果原速，主动清理无信息的机器执行与空等；用户明确偏好优先。不设固定删减率，不为凑时长丢掉必要前提、步骤或例外。

## 定位与读取

通过当前客户端实际提供的剪吧 MCP 工具操作，工具短名仅用于定位，参数以实时 Schema 和 `get_workflow_guide` 为准。MCP 未连接或缺所需权限时报告具体缺项，不绕过应用改项目文件。此 Skill 本身不配置连接。

- 先定位并固定 `projectId`、用户授权的话题或素材和 `editingMode`；已有明确目标直接沿用。话题读取 `topic_editing` 指南，明确按素材编辑时读取 `media_editing`，不为素材剪辑重建全片分段。缺目标时先读上下文，仍有歧义只问影响操作的那一项。`chapter_only` 只分段保留全片；`voiceover` 转对应流程，不套用原声 ASR。
- 同一会话已读且未变的指南复用，只加载本轮相关工作流。复用 `select_topic.source` 首批数据，沿返回的 `nextQuery` 读完目标相关原话、保护和已有倍速分页。需要新增逐词读取时优先 `compact`、`wordFormat=rows`，按返回的 `wordColumns` 解释，不再展开复制为对象；已返回的首批无需为改格式重读。
- 保留简短会话状态：范围、来源/写版本、分页完成情况、候选及残留等待、已观察的证据范围与疑点、草稿/预览任务及续读请求。更新已有记录，避免重复贴转写、Base64、整套计划或长篇过程。未返回字段仍是未知。来源或编辑版本变化重读受影响状态并重新预览；来源未变的原片证据可复用，读取 revision 不代替写版本。

## 教学判断

先理解本话题要教什么及步骤依赖，再成组拟稿。纯讲解保留论证；有演示时保留可复现的入口、关键输入/修改、提交、结果及解释。提示词、代码和参数须可读；逐字输入、AI 流式生成、滚动日志和进度变化本身不构成教学价值，不强制每段套固定教学结构。

主动定位生成、安装、构建、运行与重试中的等待，连同已有倍速一起检查。声画确认无新信息后，优先删除空等中段，保留启动与完成的必要衔接；变速用于值得展示的过程。将等待中的有效讲解、必要阅读和诊断分段保留，不能因其中有内容就保护整段执行。排错保留错误表现、判断依据、关键修复与验证结果，收紧重复失败和再次运行的空等。

重复版本比较信息完整度、准确性与衔接；强调、递进和举例有教学价值。口头填充、呼吸和停顿按听感判断。静止、无字幕、无说话均不单独构成删减理由。不把跨次生成的不同输入和结果拼成同一次成功，也不把改字幕当作改原音。不擅自重排教学顺序。

普通判断直接进行；重复、纠正或排错取舍不清时读 [编辑对照案例](references/editorial-examples.md)。出现录屏或声画混合时读 [操作与声画对齐](references/mixed-content.md)，纯讲解不必加载。疑点先补证据；仍无法核实时暂留并报告未完成的核对范围，不把未核实空等当作已完成清理。

## 取证、预览与应用

概览只导航，不能证明过程已观察。按候选和疑点复用未变的证据，必要时补听原声、展开高清原帧或查看连续片段；细小参数不可读就取足够清晰的画面。时间删减/变速须满足当前 MCP 的原片覆盖要求，保留真实来源、时间基准与保护权限。删除原话默认逐词 `removals + word_exact`；已核实的无词空等使用 `time_ranges`，不借相邻词或扩大词切口包住等待。无法实际听看时明确能力缺口，不声称已核对或应用未审阅方案。

形成候选后生成真实预览，按返回 `waitQuery` 等待、`readQuery` 读媒体、`nextQuery` 完成同页交付和分页；超时续等同任务，避免固定短轮询或重复渲染。沿续读保留本次交付偏好和实际已知资源 ID；`knownAssetIds` 仅去重，路径、`ready` 或交付状态不等于已观看。完整媒体分批读取，不靠缩图、截音或跳过窗口节省 token。

按草稿映射和实际倍速检查成片残留等待：连续超过 10 秒的疑似纯机器等待必须逐段复核，同时检查多段短等待的累计拖沓。10 秒是复查触发条件；较短的已确认空等也应清理，必要讲解、阅读和诊断按内容保留。不能以“已加速”通过验收；有疑点时补看残留范围。

实际试听/看清片头、片尾和全部剪接及变速接点，并核对删减影响的教学步骤及“点击这里/看这个结果”等指代。检查吞字、爆切、参数可读性、动作及声画同步；失败先局部修订再核对受影响内容。只有用户已授权应用且审阅通过才提交；只要方案就停在方案。预览若省略过期字幕，注明它仅用于声画核对，字幕仍待处理，不冒充最终字幕效果。

完成后简述实际删留/变速理由、教学内容保留情况、残留长等待的理由及未解决疑点；不自动转入封面、发布或导出。按 MCP 返回状态结束对应审阅，已自动结束就不重复调用；放弃或审阅完成但不应用的明确候选可 `finish_media_review`，保留仍在审阅的其他任务。
