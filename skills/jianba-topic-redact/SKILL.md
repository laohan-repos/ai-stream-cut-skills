# 剪吧话题打码

遮挡指定话题中识别出的敏感画面，保留教学路径、参数标签、必要结果、原声或配音，以及已有剪辑、字幕和其他图层。按用户指定的敏感类别和保留要求执行，不用整屏长时间遮挡代替区域定位。

用户明确要求打码时，核对通过后应用对应方案；只要检查或文字方案时交付候选与疑点，未要求看效果就不启动整题渲染，也不应用。已有目标与授权直接沿用，歧义只问影响操作的一项。尽量在剪辑与字幕稳定后处理，不为此重剪、分段或运行 ASR。

## 定位与取证

通过当前客户端实际提供的剪吧 MCP 操作，工具短名只用于定位，参数以实时 Schema 为准。首次读 `get_workflow_guide(workflow=redaction)`，同会话已读且未变则复用；不同时加载剪辑或字幕 Skill。缺必要能力时说明具体缺项，不绕过应用改项目文件。

固定 `projectId` 和真实话题 `scopeId`；“当前”结合激活标签及话题列表定位，已有明确目标沿用。找不到话题不改成默认 `all`。用 `get_redaction_context` 沿 `nextQuery` 读完目标时间线，保存画布、原片映射、已有层、字幕、聚焦/画中画、来源与写版本。话题时间是 `scope_output`，不把全片播放秒数或原片秒数直接提交。

从用户指出的位置和范围开始核对。未指定区域时，按目标话题的画面及场景变化查找密钥、密码、账号、联系方式、证件或二维码等候选；只记录类别、时间和区域，不在报告中转录完整敏感值。概览或稀疏帧只用于导航，细小文字、短暂弹窗、滚动与移动须补高清原帧和连续片段。已有原片证据来源与映射未变可复用，未观察区间仍未知，不能据几张图宣称全话题无遗漏或自动识别/跟踪成功。

## 遮挡方案

敏感文字和二维码默认使用完整不透明色块，遮挡留足空间和时间余量，首尾全强度、不淡入淡出；用户明确样式优先，并实际检查其遮挡效果。固定位置用矩形；滚动、切页、缩放或窗口移动时，读 [坐标、运动与作用范围](references/geometry-and-scope.md)，根据真实观察拆段或设置关键帧，不靠两端位置猜中间轨迹。

源画面敏感区通常用 `target=main`，核对聚焦及同源小窗；最终画布区域用 `output`，同时检查字幕、动画与独立画中画。不能把拼图格子或标签栏坐标当原画面坐标。检查源区间是否在其他话题复用，不能仅凭 scopeId 承诺绝对隔离；影响超出既有授权且无法安全隔离时保留草稿，说明涉及范围与能力缺口，不静默扩大修改。

先检查已有打码的类型、范围、有效性与实际遮挡。已满足需求的区域不新增重复层；同批多个区域成组预览。新增层省略 id，修正时只用本 scope 的真实已有 id；未列出的层继续保留，不为通过校验移除其他范围的图层。声音或外挂字幕也出现敏感内容时单独报告状态，画面打码不代表它们已处理；原片文件仍保留。

## 预览、应用与回查

用 `preview_redaction_plan` 提交本次新增/替换层，生成真实预览。当前接口仍渲染整个话题，读取短窗只减少交付量；按 [审阅与状态](references/review.md) 复用同一 job，不将多次创建当轮询，也不编造不存在的局部渲染参数或通用等待调用。

用实际返回的续读请求及同一 jobId 取得 `get_redaction_preview` 媒体，覆盖全部拟打码区间与必要前后文。核对首次露出、最后露出、快速移动和中间状态，以及边缘、小窗、聚焦和独立素材，检查敏感内容不可读且教学操作仍清楚。采样图、路径、ready、reviewed 或一次媒体交付不等于连续过程已审阅。能力不足、漏码或位置存疑时先补证据/局部修订，未解决不应用。

只有同一草稿 `readOnly=false`、ready、`matchesCurrentContent=true`，且真实声画核对通过，才按授权 `apply_redaction_plan`。保留草稿原绑定；来源、字幕、效果或版本变化时重读并重新预览，不只替换 expectedVersion。多个话题提交串行进行，原片证据可复用，旧剪后预览不代替新方案。

应用后按返回的 changed、图层及新版本回读目标上下文，核对新增/替换层、已有遮挡和实际影响。成功应用后预览索引告警不等于应用失败，不重复提交。需要当前封面或发布截图时用最新上下文的 `safeFrameRequest` 获取已应用效果的只读快照，不拿原片或旧草稿当安全图，也不自动进入导出。

完成说明已处理的类别与区间、实际核对范围、同源传播、未观察/未解决项及声音/外挂字幕状态。只报告实际完成的覆盖，不声称整片或所有敏感信息均已脱敏。
