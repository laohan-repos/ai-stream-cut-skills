# 定位与时间坐标

用户用“这里”“刚才那句”、播放秒数或原话指代修改位置，或定位跨素材、跨剪接、变速处时，先读本页。参数、字段及可用能力以当前工具 Schema 和 `get_workflow_guide` 返回的指南为准。

## 先把指代落到真实内容

用 `get_editor_context` 核对激活项目、当前范围、播放模式、选区和位置，固定 `projectId`。选区中的 word、clip、caption、gap ID 要与当前上下文中的实体核对；ID 本身不是时间。没有窗口或选区为空时，继续读取已有项目和目标范围，不推断用户没有项目，也不凭空补选区。

有明确选区时先检查它是否对应用户说的内容；只有播放位置时，以 `sourceTime` 和实际播放模式定位附近短窗口。`playbackTime` 属于当前模式，不能一律当全片成片时间。预览位置还需对应具体任务及其窗口映射。若状态过旧、来源不明或位置矛盾，重新读取后再判断。

用户给原话时，可用 `get_transcript(query=...)` 搜索定位，再读取目标附近上下文；恢复请求还须检查已删和部分保留词，不能只搜当前保留词。结合前后句、素材名和播放位置消歧；同一句有多个合理匹配时，只问能区分目标的一项。位置和边界已清楚便继续，不索要用户重新报全部时间。

## 明确坐标再映射

- 全片成片秒数从全片输出起点计算；话题成片秒数从该话题输出起点计算。两者都受删留、顺序和速度影响，不能直接互换。
- 全局原片秒数指项目源时间；素材内秒数从该素材的零点计算。素材上下文的 `sourceOffset` 是源偏移，列表 `offset` 是分页偏移。素材方案使用素材内坐标，取证请求则沿用后端已换算的全局原片参数。
- 按当前时间线返回的原片范围、输出起止和实际映射逐段换算。成片区间跨剪接可对应多个不连续原片区间；同一源段复用时也可能对应多个输出位置。保留这些分支，不以首尾包围范围代替。
- 普通恒速片段可按明确速度映射；曲线变速、定格和组合内容必须读取其实际映射，不能只除以 speed、平均速度或累计删减时长。定格期间多个输出位置对应同一源时刻；映射不足便补读相关上下文，不猜边界。

## 少读，但不漏读约束

Schema 支持时，给 `get_media_edit_source` 传 `range:{start,end,timebase}`：素材内时间用 `media_source`，全局原片时间用 `source_global`，全片成片时间用 `project_output`。话题成片位置先转换为可靠全片/原片坐标，不能冒充 `project_output`。`contextSeconds` 默认 2，可按理解和接点需要调整，不以较小数值隐藏必要上下文。

按 `readRange.requestedSourceRanges/sourceRanges` 理解请求与含上下文范围，读完其集合分页即可；重叠的原话、保护与片段保留完整边界，不能把条目超出查询端点误当成扩大的修改授权。跨剪接可能得到多个源区间，`includesOtherMedia` 或 `includesRepeatedSourceOccurrences` 为真时核对全部实际影响位置。取证提示只指向首个源区间时，按后端时间基准补齐其余处理范围。

范围读取不证明整片已读，范围外信息仍未知；后端继续全局校验保护和范围外剪辑决定。语义、映射或边界不够时针对疑点扩大读取。旧接口无 `range` 时沿其原流程，不编参数。话题原话与倍速仍可独立分页；`summary`、省略字段或空页不证明集合为空。检查 `readInfo.coverage`；素材词项仅有 retained 时，保护以 protectedRanges 和后端校验为准。字段投影不代替必要保护读取，不为换格式重读全片。

定位结果附当前版本和来源绑定。项目、源文件、分段或映射变化后，重读并重建受影响草稿，不能只替换版本号沿用旧方案。局部预览按本次真实 `reviewWindows` 与全部必要接点审阅；回退完整素材预览时沿其清单，不自行删减门禁。
