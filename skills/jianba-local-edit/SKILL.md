# 剪吧局部修改

把用户指出的问题改准确，沿用现有删留、倍速、顺序与声画效果。修改限定在目标及必要衔接范围；时长改变后，后续成片时间正常顺延。

“恢复这句、删这段、这里改成 4 倍速”等明确指令授权完成对应修改，核对通过后应用；“看看怎么改、先给方案”停在方案。位置或范围仍有影响结果的歧义时，只问必要的一项。此 Skill 独立执行，无需先加载全片精剪 Skill。

## 定位与读取

使用当前客户端实际提供的剪吧 MCP 工具；短名仅用于定位，参数以实时 Schema 和相应 `get_workflow_guide` 为准。缺连接、权限或必要能力时报告具体缺项，不绕过应用改项目文件。

- 固定 `projectId`、目标素材/话题及项目模式。已有明确目标直接沿用；“当前、这里”可读 `get_editor_context`，结合激活标签、选区、播放模式和位置定位。引用原话、时间坐标不清、多个匹配或复杂变速时读 [定位与时间映射](references/positioning.md)。
- 选择能保留现状的路径：通常用 `media_editing` 做素材局部修改；已进入原片话题剪辑且明确针对该话题时用 `topic_editing`。不为局部修改首次重建完整原片话题、重新分段或重跑全片精剪。`chapter_only` 缺编辑权限时报告；配音项目沿其声音来源，不恢复原片原声。
- 同一会话复用未变的指南、目标上下文及真实证据。按工具要求读完目标相关删留、恢复、保护、原话和倍速分页；复用 `select_topic.source` 首批，沿 `nextQuery` 续读。新增逐词读取优先 `compact`、`wordFormat=rows`，按 `wordColumns` 解释；未返回字段仍未知，不为换格式重读。
- 只维护简短状态：用户意图、定位依据、目标与时间基准、来源/写版本、分页进度、候选范围、真实证据与疑点、草稿/任务及续读请求。更新已有记录，避免重复贴转写、Base64、整套方案。版本或来源变化重读受影响状态并重新预览；未变的原片证据可复用，读取 revision 不代替写版本。

## 最小修改

基于当前状态提交用户要求的增量。先核对候选的实际原片范围与已有删留、速度和保护，再检查草稿实际变化。范围外的剪辑决定继续沿用；不以全局撤销代替定向恢复。

话题原话删减默认 `removals + word_exact`；已核实的无词等待及素材剪辑使用实际工具支持的时间区间，不借相邻词包住空等。倍速是绝对目标，`speed=1` 恢复原速，不与已有速度相乘。恢复、保护冲突或接点修复时读 [恢复与接点取舍](references/restoration-and-seams.md)。

删除或变速前核对真实原片声画，证据须覆盖整个处理区间，遵守来源、时间基准、保护与完整词边界。静止、无字幕或无说话不单独构成删减理由。机器执行确认无新信息后优先删中段，保留必要讲解、关键操作、可读输入与结果；值得展示的演变才变速，不因已有加速就保留长空等。不跨次拼接输入与结果，不把改字幕当作改原音。

## 预览、应用与验证

同一目标中兼容的修改成组预览；冲突区间先解决，避免一项失败后擅自应用其余项。草稿应显示预期变化及实际恢复/删减范围。发现范围外决定被改变，先修正方案；字幕分组或过期状态阻塞时说明具体原因，保留人工内容，不自行重置自动字幕。

应用型任务按所选素材/话题流程校验草稿并创建真实预览。按返回的 `waitQuery` 等待、`readQuery` 读媒体、`nextQuery` 补齐本页交付及后续页；续等同任务，不固定短轮询或重复创建。保留本轮交付偏好，`knownAssetIds` 仅去重真实已交付资源。沿实际返回完成读取，不编造通用工具名或参数。

现有素材/话题预览可能覆盖较大范围，必须满足其片头、片尾与全部剪接/变速接点的必要 WAV 和真实帧交付，并实际核对声画；路径、ready 或交付状态不等于已观看。重点核对修改内容、吞字/突切、指代、参数阅读及同步，有疑点补看受影响范围。不以只看修改点、缩图或截音省略门禁，也不为避免门禁切换直接删除工具。无法实际听看时报告能力缺口，保留未审阅草稿，不宣称核对或应用成功。

按用户授权应用同一份已审阅草稿；来源或版本冲突重新读取、拟稿和预览，不能只换版本强交。应用后以返回的实际范围、`changed`、最新写版本与时长确认结果，核对目标局部；`changed=false` 说明没有新增变化，不冒充修改成功。确认范围外剪辑决定仍保留，必要时局部补查，不重读全片。

完成后简述修改位置、实际改动、衔接与未解决疑点。按返回状态结束对应审阅，已自动结束不重复调用；放弃的明确候选可 `finish_media_review`，保留其他仍在审阅的任务。
